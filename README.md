# YOSUGA（よすが）

**Independent Technology Project | Japan**

日本発の独立系テクノロジープロジェクト

## About YOSUGA / YOSUGAについて

YOSUGA is an independent technology project focused on the integrated development of hardware, software, industrial design, materials, and human–device interaction. Our primary development priorities are VÄLK mobile devices and the ÆTHER operating system. Additional research areas include digital imaging, personal computing, modular hardware, repairability, and material engineering.

YOSUGAは、ハードウェア、ソフトウェア、工業デザイン、素材技術、人と機器の接点を一体として設計する独立系テクノロジープロジェクトです。VÄLKおよびÆTHERの開発を主軸とし、独立型デジタルカメラ、PC、拡張ハードウェア、修理性、素材技術も研究・構想しています。

## NØVA Replaceable Architecture / NØVA交換式筐体構造

Both AXIOM and ELEMENT are intended to support user-replaceable exterior panels and protected battery modules without specialized repair tools. CHROMA panels form the actual exterior, rather than conventional external cases.

AXIOM・ELEMENT両機種で、専門的な修理工具を必要とせず、ユーザー自身が背面パネルと対応する専用保護バッテリーモジュールを交換できる構造を目指します。CHROMAパネルは保護ケースではなく本体外装そのものです。

| Assembly | Development direction |
|---|---|
| Mainboard / display | Fixed main chassis |
| Camera / DialNav / fingerprint sensor | Main-chassis-mounted |
| Antenna | Independent of exterior where feasible |
| Wireless charging | Main-chassis integration under evaluation |
| Battery | Dedicated protected module; independently removable through rear panel |
| Exterior | Model-specific interchangeable CHROMA panel |
| Attachment | Reusable retention mechanism; tool-free target |
| Battery monitoring | Health and thermal monitoring, compatibility management |
| Parts supply | Long-term exterior and battery availability; recycling support research |

Battery replacement is intended with the device powered off, using compatible, professionally validated modules. Cross-model physical panel compatibility is not assumed. IP68 is an unvalidated development target. Repeated panel replacement, sealing, wireless charging and high-power charging require professional system-level safety validation.

電源を切った状態で、安全性・適合性が確認された専用交換電池を利用する構想です。AXIOMとELEMENTの外装寸法の共通化は前提としません。IP68は未検証の目標であり、繰り返し交換、防水、無線充電、高出力充電の両立には専門技術者による検証が必要です。
